# 三科学习计时器

面向数学、英语、408 的浏览器学习计时页，提供开始、暂停、恢复、结束、科目分类和本机记录。旧的未分类记录保持独立标识。

## 启动

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8766/`。也可直接用浏览器打开 `index.html`，但浏览器对本地文件存储及跨域请求的行为可能不同。

## 文件与数据

- `index.html`：界面、计时状态机、科目统计和浏览器存储。
- `timer-control.js`：本地遥控同步。
- `global-shortcut-events.js`：外部快捷操作事件适配。

计时记录保留在使用者自己的浏览器中；仓库不含原使用者的记录。遥控与学习值守需要另行运行本地配套服务并完成配对；不附带任何配对令牌。

## 公开范围

这是从本机工作源码整理的公开副本。只包含代码、运行逻辑和必要结构，不包含真实学习记录、完整对话、学习画像、健康记录、原始教材、凭据、浏览器数据或运行数据库。路径中的 `YOUR_USER` 必须按本机环境配置。源码检查不代表已在另一台电脑部署成功；本次发布不启动服务、不写入真实学习库。
